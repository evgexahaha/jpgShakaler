# jpgShakaler (PixelLab)

Легковесный клиентский веб-конвертер и оптимизатор изображений, работающий полностью в браузере без отправки данных на сервер.

## Возможности

- **Конвертация форматов**: PNG, JPG (JPEG), WebP.
- **Масштабирование и ресайз**:
  - Быстрые пресеты (Оригинал, 75%, 50%, 25%, 4K, 1080p, 720p и др.).
  - Задание ширины и высоты в пикселях или масштаба в процентах.
  - Режимы подгонки: с сохранением пропорций (fit), точный размер (stretch), обрезка (cover).
- **Сжатие и контроль качества**:
  - Настройка качества JPG/WebP.
  - Ограничение максимального размера файла в КБ (автоматический подбор параметров).
- **Трансформация и обработка**:
  - Поворот на 90° / 180° / 270°.
  - Отражение по горизонтали и вертикали.
  - Фильтры: Ч/Б, сепия, негатив.
  - Наложение текстового водяного знака.
- **Пакетная обработка**:
  - Выбор и drag-and-drop нескольких фото сразу.
  - Скачивание всех обработанных файлов в один клик.
- **Приватность**:
  - Все операции производятся на клиенте (Canvas API).
  - Автоматическое удаление метаданных (EXIF, GPS, модель камеры).

## Запуск

Просто откройте `index.html` в любом современном браузере.
